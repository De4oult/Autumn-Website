---
title: Первое приложение
description: Создайте первую точку входа, от которой начнет расти осенний сад приложения.
---

Первое приложение может быть совсем маленьким. Важно то, что объект приложения становится единой точкой входа для маршрутов, конфигурации и будущих модулей.

## Минимальная конфигурация

```python
from autumn import Autumn

import uvicorn

app = Autumn(
    discover = 'app.controllers'
)

if __name__ == '__main__':
    uvicorn.run(app)
```

## Почему стоит начать именно так

- `Autumn(...)` задаёт чёткую границу приложения.
- Runtime остаётся явным, без скрытой CLI-магии.
- Когда позже появятся контроллеры и сервисы, у них уже будет стабильный корень.

## Как подключаются остальные части

Контроллеры, сервисы, leaf-функции и hook'и должны находиться в импортированных модулях. Через `discover` укажи модуль, в котором они расположены. В этом примере `app.controllers` подключает пакет контроллеров; один модуль передаётся строкой, а несколько можно передать кортежем или списком.

На следующем шаге мы создадим первый контроллер в `app/controllers/hello.py`. Сборка приложения останется в `main.py`.
